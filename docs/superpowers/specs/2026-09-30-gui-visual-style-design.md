## 1. 最终决策

**采用 TNO「硅晶之梦」风格：复古未来主义 + 合成器浪潮。**

| 维度 | 结论 |
| :--- | :--- |
| 配色 | 极暗蓝黑→青绿基底（`#081018` → `#0A161A`）；霓虹青 `#58C8C0` 主强调、黄 `#C8C000` 次强调 |
| 结构 | 直角 · 多重 1px 发丝线（一亮两暗）· 板块无边框 · 全页仅 3 条分割线 |
| 文字 | 半透明 rgba + 四层轮廓辉光 + 描边；按重要性分三级给光 |
| 布局 | **单页平铺**（参数与状态监视同屏）；连接选项卡固定**左上角**，点击展开详细设置 |
| 设备标识 | 型号**不做常驻标题**，连接后显示于连接选项卡右侧，用固件 USB 终端**同款 ASCII 艺术字** |
| 字体 | Electrolize（标题）+ Cascadia Mono（数值）+ Noto Sans SC（中文），全部 SIL OFL 1.1 |
| 数据可视 | 实心饼图（无描边无缝）+ 实心面积图 + 双向网格；分段条用 LED 语汇 |

## 2. 决策过程（三轮，含两次推翻）

### 第一轮：M3 深色 + token 化的档案风格 → **推翻**

最初按「工程仪器」定位，做了 Material 3 深色 + 去饱和档案配色（雾青纸面板）的方案。
推翻原因：**素材实测发现方向搞反了** —— TNO 事件窗是**浅色纸面 + 深色字**浮在深色外壳上，
而我做成了全深色面板配浅色字。

### 第二轮：浅纸面板 + 深色 chrome → **推翻**

按实测修正为「浅纸浮于深色外壳」的双层结构。
推翻原因（Kaiser 决策）：**事件窗那套明暗割裂的配色不适用于本工具** ——
本工具是长时间盯读的控制台，不是翻阅文档；双层明暗制造视觉负担且割裂整体感。

### 第三轮：统一深色 + 硅晶之梦 → **采纳**

回到统一深色体系，视觉参照收窄到 TNO **硅晶之梦** 这一个子风格，
关键词：复古未来主义、合成器浪潮。

**意外收获**：硅晶之梦本身就是霓虹青 + CRT，与固件 USB Terminal 的蒸汽波配色**天然同源** ——
前两轮需要费力折中的"终端与上位机视觉统一"问题，本轮自动消解。

## 3. 实测推翻的三处常见印象

记录在案，避免以后有人凭印象改回去：

| 项目 | 常见印象 | **实测结论** |
| :--- | :--- | :--- |
| 面板角 | 切角 / 斜切 | **90° 直角**（像素位图显示竖线直接接入横线） |
| 次强调色 | 热粉 `#FF00FF`（合成器浪潮招牌） | **黄 `#C8C000`**；品红仅占 **1.5%** |
| 背景色温 | 中性灰或单纯青绿 | **双段偏色**：深处蓝黑 `#081018`（B>G），面板层青绿 `#081010` |
