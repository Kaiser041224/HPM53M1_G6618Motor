# 磁编码器角度传感设计（双 KTH7823 + 差齿游标）

- 日期：2026-09-18
- 状态：**草案**（机械拓扑与齿数分配待 Kaiser 最终确认；游标公式待标定验证）
- 关联：`2026-09-18-m1-board-bringup-design.md`（驱动与硬件事实）、`Doc/datasheet/encoder_kth7823.pdf`
- 定位：为后续上层算法（出轴绝对角度解算）提供设计依据；驱动实现见 `intf_encoder` / `app_encoder`

## 1. 机械拓扑

Kaiser 描述原文：

> 该电机有巨大中空，转子所在轴通过一个外齿圈分别与两个带磁铁的齿轮啮合（两个编码器的齿轮不互相接触），
> 其中转子编码器的磁铁所在齿轮是 49:49，出轴编码器磁铁所在齿轮比转子磁编所在齿轮是 49:50，
> 整个磁编与转子关系是 49:49:50，利用差齿的游标法推算带减速器后的出轴角度。

本设计理解（**待确认**）：

| 齿轮 | 齿数 | 与转子关系 |
| :--- | :--- | :--- |
| 转子轴外齿圈 | 49 | 随转子 1:1 |
| 转子编码器小齿轮 | 49 | 49:49 → 每转子 1 转 = 1 转 |
| 出轴编码器小齿轮 | 50 | 49:50 → 每转子 1 转 = 49/50 转 |

- 两个编码器小齿轮均与同一齿圈啮合，互不接触。
- 编码器：双 KTH7823，单圈绝对 16bit，SPI mode3，SCK ≤10MHz。
  - 转子端 → **SPI3**（PA10–PA13，CS0）
  - 出轴端 → **SPI1**（PA26–PA29，CS0）
- 出轴端编码器**不直接测出轴**，其读数用于游标解算（见 §2）。

## 2. 游标测角原理

设转子机械角 θ（单位：圈），两编码器单圈读数归一化为 0..1：

- φ1 = frac(θ)                  （49T 小齿轮，1:1）
- φ2 = frac(θ × 49/50)          （50T 小齿轮）

差值：

- Δ = frac(φ1 − φ2) = frac(θ / 50)

即：**每转子 1 转，Δ 前进 1/50 圈；50 转子转内 Δ 单值**。
→ 游标提供 **50 转子转的绝对范围**（转子多圈绝对角度）。

- 粗绝对角：θ_abs = 50 × Δ（圈，0..50）
- 精插值：用 φ1（16bit）修正 θ_abs 的小数位/消除跳变（算法细节待定）
- 出轴角：θ_out = θ_abs / N_reducer（N = 减速比，**待确认**）
  - 若 N 与 50 相关（如 N=50），则 50 转子转 ≈ 出轴 1 转，即出轴整圈绝对定位。

> 符号方向：取决于齿轮旋向、磁铁装配与 KTH7823 的 RD 寄存器设置，标定时确定。

## 3. 分辨率与精度

| 项 | 数值 | 备注 |
| :--- | :--- | :--- |
| 单编码器分辨率 | 360°/65536 ≈ **0.0055°** | 16bit 单圈 |
| 游标等效分辨率（折算到转子单圈） | 0.0055°/50 ≈ **0.00011°** | 理论值 |
| 单编码器非线性误差 | ±0.35° | KTH7823 表 8，主导项之一 |
| 输出噪声（1σ） | 0.015° | KTH7823 表 8 |
| 实际精度 | **由齿隙、齿轮偏心、磁铁安装误差、编码器非线性支配** | 需实测评估 |

- 分辨率 ≠ 精度：游标差值对两路编码器的零位/相位一致性、齿圈跳动敏感。
- 动态误差：两路顺序采样间隔 ~10µs，而 Δ 的变化率仅为转子转速的 1/50 →
  对差值影响可忽略，无需同步采样机制（20kHz 采样下）。

## 4. 与驱动/配置的关系（上层算法需要的接口）

- 两路编码器均工作在单圈绝对模式，驱动层只提供**原始 16bit 读数**：
  `app_encoder_read_raw(APP_ENCODER_ROTOR, &raw)` / `APP_ENCODER_OUTPUT`。
- 零点（Z，0x00/0x01）与方向（RD，0x09）为**一次性 MTP 配置**（寿命 1000 次写）：
  标定阶段写一次，运行期只读；驱动提供显式配置 API，自检/周期路径禁止写。
- 游标解算（多圈展开、方向/零位对齐、齿隙补偿、减速比换算）属**上层算法**，
  不在驱动内实现。
- 驱动保证：单次读 ~µs 级、确定性、无阻塞风险（超时保护）、错误可计数。

## 5. 标定与验证计划（后续，非当前驱动阶段）

1. 上电后手动转动转子：确认两路读数变化方向与 49:50 速率关系。
2. 在 50 转子转范围内记录 Δ 的线性度与回程差（评估齿隙/偏心）。
3. 确定减速比 N、出轴角公式的符号与零位对齐方法。
4. （可选）外部基准（输出端刻度/角度仪）校核绝对精度。
